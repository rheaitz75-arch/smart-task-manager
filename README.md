# Smart Task Management System

A Flask-based web application for managing tasks with authentication, analytics, REST APIs, PostgreSQL integration, and real-time updates using WebSockets.

## Features

- User Registration & Login
- Add / Update / Delete Tasks
- REST API Support
- PostgreSQL Database
- Analytics Dashboard
- Real-Time Updates with SocketIO
- Responsive UI

## Technologies Used

- Python
- Flask
- PostgreSQL
- Flask-SocketIO
- Pandas
- NumPy
- HTML/CSS

## Installation Steps

1. Clone repository

```bash
git clone https://github.com/rheaitz75-arch/smart-task-manager.git
```

2. Navigate into project

```bash
cd smart-task-manager
```

3. Create virtual environment

```bash
python3 -m venv venv
source venv/bin/activate
```

4. Install dependencies

```bash
pip install -r requirements.txt
```

5. Run application

```bash
python3 app.py
```
